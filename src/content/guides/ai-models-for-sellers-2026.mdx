If you are choosing an AI model for seller work in late 2026, the four providers' own documentation, as listed on November 11, 2026, points you to these starting models: Anthropic says to start with Claude Opus 5.5 for most workloads, <C id="ai-models-for-sellers-2026-02"/> OpenAI says to start with GPT-6 Astra, <C id="ai-models-for-sellers-2026-15"/> Google lists Gemini 4 Argon as its flagship reasoning model, <C id="ai-models-for-sellers-2026-26"/> and Moonshot AI names kimi-k3.1-pro as Kimi's flagship. <C id="ai-models-for-sellers-2026-34"/> The differences that matter for a seller are less about the names than about four documented facts: the knowledge cutoff, whether the model can search the web, whether it reads PDFs, and what each million tokens costs. This page sets those out provider by provider, then maps common seller tasks to the feature that decides them.

This page covers the developer (API) documentation of each provider. "ChatGPT" in the title is used only as the familiar name for OpenAI's GPT models; everything on this page about OpenAI comes from its API documentation. ChatGPT app plans are not covered, and neither are the Claude, Gemini or Kimi consumer apps, whose features and prices are on separate pages.

Kimi's introduction also states the flagship's window as "up to 1M tokens." <C id="ai-models-for-sellers-2026-35"/> Two practical points come out of this table.

**A context window is not an output length.** The context window is how much the model can take in; the max output is how much it can write back in one response. Every Claude and OpenAI model above reads around a million tokens but writes at most 128,000 per response, <C id="ai-models-for-sellers-2026-03"/> <C id="ai-models-for-sellers-2026-16"/> and Gemini 4 Argon defaults to 65,536 output tokens unless long decode is used. <C id="ai-models-for-sellers-2026-27"/> If you paste a 3,000-row catalog and ask for a rewritten title for every row in one reply, the output limit, not the context window, is what you hit first. Splitting the job into smaller requests avoids it.

**A knowledge cutoff is a hard edge.** A model with a Jun 2026 cutoff has no built-in knowledge of a fee schedule, tariff action or marketplace policy published after that month. Anthropic says its web search tool exists to give Claude "up-to-date information beyond its knowledge cutoff," <C id="ai-models-for-sellers-2026-10"/> and Google says the same of Grounding with Google Search. <C id="ai-models-for-sellers-2026-30"/> Without a search tool or a source you supply, an answer about a recent change can only reflect what the model learned before its cutoff.

<Callout type="warning" title="Fees and duties: read the source, not the model">
Even with search turned on, a model's answer is a summary of web pages. For a referral fee, an FBA fee or a duty rate, open the cited page and confirm the number on the official source before you price a product. OpenAI's web search answers include inline citations by default, <C id="ai-models-for-sellers-2026-24"/> and Claude's responses cite the sources drawn from search results, <C id="ai-models-for-sellers-2026-10"/> so the source link is there to check.
</Callout>

## Features sellers use, by provider

### Reading supplier PDFs, invoices and spec sheets

All four providers document a way to give the model a PDF, with different mechanics:

- **Anthropic:** you can ask about "any text, pictures, charts, and tables" in a PDF, up to 600 pages per request (100 when the request's context window is under 1M tokens) and 128 MB per request on the first-party API. <C id="ai-models-for-sellers-2026-12"/> Each page is converted to an image and its text extracted alongside, <C id="ai-models-for-sellers-2026-13"/> so content that appears only as an image on a page is still part of what the model receives.
- **OpenAI:** on vision-capable models the API "extracts both text and page images" from the PDF; each file must be under 50 MB. <C id="ai-models-for-sellers-2026-25"/> GPT-6 Astra accepts image input. <C id="ai-models-for-sellers-2026-18"/>
- **Google:** PDFs up to 50MB or 1000 pages, with each page counted as 258 tokens. <C id="ai-models-for-sellers-2026-31"/> Gemini 4 Argon lists PDF among its inputs. <C id="ai-models-for-sellers-2026-28"/>
- **Moonshot AI:** files go through a file interface that extracts text from pdf, doc and txt files; the extracted text is then placed in the conversation as a system prompt. <C id="ai-models-for-sellers-2026-40"/>

### Images and languages

All current Claude models support image input and "multilingual capabilities." <C id="ai-models-for-sellers-2026-04"/> Moonshot describes kimi-k3.1-pro as having native visual understanding. <C id="ai-models-for-sellers-2026-34"/> The OpenAI and Google model pages checked list image input <C id="ai-models-for-sellers-2026-18"/> <C id="ai-models-for-sellers-2026-29"/> but the pages fetched for this guide did not state language support, so check the provider's documentation for the languages you sell in.

### Web search

Claude's web search tool returns citations for its sources <C id="ai-models-for-sellers-2026-10"/> and is priced per search. <C id="ai-models-for-sellers-2026-11"/> GPT-6 Astra supports web search and file search tools in OpenAI's Responses API. <C id="ai-models-for-sellers-2026-18"/> Gemini 4 Argon supports Search grounding, URL context and file search, and its page shows a latest update of October 2026; the page states no knowledge cutoff. <C id="ai-models-for-sellers-2026-28"/> Kimi's models do not reach the internet by default, <C id="ai-models-for-sellers-2026-38"/> and search is offered as separate Web Search Basic, Web Search Pro and URL Fetch APIs billed per call. <C id="ai-models-for-sellers-2026-39"/>

## Amazon's own generative AI listing tools

Amazon builds generative AI into listing creation. It says sellers can use AI to create titles, product bullet points and product descriptions, <C id="ai-models-for-sellers-2026-42"/> starting from a few words, an image or a URL from their existing website. <C id="ai-models-for-sellers-2026-43"/> Amazon attaches a condition: if you use the proposed content, you agree you have reviewed it and that it is accurate, complete and compliant with all applicable laws and Amazon policies. <C id="ai-models-for-sellers-2026-44"/> For how Amazon's shopping assistant reads the finished listing, see [Rufus, now Alexa for Shopping](/guides/rufus-listing-optimization/); for AI-generated people in images, see [the disclosure rules](/guides/ai-image-tagging-rule/).

## Scope of this page

This is a snapshot of provider documentation on one date, not a ranking and not advice on which provider to contract with. Model lists, cutoffs and prices change often, and API terms, data-use and privacy terms are set in each provider's own agreements, which this page does not summarize. For a contract or data-protection question, the provider's published terms and your own counsel are the route.

## How to confirm it before you choose a model

Open each provider's own pages and read the current figures: Anthropic's models overview, pricing, web search tool and PDF support pages on platform.claude.com; OpenAI's models list, individual model pages, pricing, web search and file inputs guides on developers.openai.com; Google's Gemini models list, each model's own page (limits and capabilities), pricing, Google Search grounding and document processing pages on ai.google.dev; and Moonshot AI's introduction, model list, pricing, web search and file guides on platform.kimi.ai. If a figure you need, such as a Gemini 4 Argon price or a Kimi knowledge cutoff, is not on those pages, ask the provider rather than relying on a third-party summary. For Amazon's listing tools, read Amazon's own seller pages on sell.amazon.com, and use [Seller Central reports](/guides/seller-central-reports/) to check what your catalog actually contains before a bulk rewrite.
