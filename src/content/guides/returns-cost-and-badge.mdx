Amazon charges sellers for returns in two published ways. For FBA orders on Amazon, the returns processing fee is "charged on orders when Amazon provides a customer with free return shipping." <C id="returns-cost-and-badge-01"/> For Multi-Channel Fulfillment (MCF) orders from other channels, Amazon publishes a per-unit return fee by size tier and weight — $4.70 for a large standard item over 1 lb to 2 lb. <C id="returns-cost-and-badge-10"/> <C id="returns-cost-and-badge-14"/> This page covers what is public: when the FBA fee applies, how its scope has changed, the MCF return fee table, the waivers, and the reports you can use to track it.

## When the FBA returns processing fee applies

FBA's fulfillment service already includes returns handling. Amazon describes fulfillment costs as covering picking, packing and shipping, "as well as handling customer service and returns." <C id="returns-cost-and-badge-02"/> The returns processing fee is a separate charge, and its trigger is specific: Amazon gives the customer free return shipping. <C id="returns-cost-and-badge-01"/>

Its scope has widened over time:

The 2023 announcement described the expansion this way: Amazon would "expand the returns processing fee to apply to high return-rate products in all categories, excluding apparel and shoes." <C id="returns-cost-and-badge-04"/> It added that the fee would "only apply to products that have the highest return rates relative to other products in their category," starting June 1, 2024. <C id="returns-cost-and-badge-05"/> The benchmark is your category, not an absolute rate. Amazon's stated purpose was cost and waste: "This fee will address the operational costs of returns and reduce waste." <C id="returns-cost-and-badge-24"/> For apparel and shoes, which already carried the fee, Amazon said existing returns processing fees "will remain unchanged on average." <C id="returns-cost-and-badge-25"/> The per-unit FBA fee amounts and the return-rate thresholds are published in Seller Central; look up "returns processing fee" there.

## MCF return fees by size

For MCF, Amazon publishes the full table. "Amazon charges return processing fees for items returned through MCF," and the fees are "based on the product's size tier and weight and include return logistics transportation, regrading, and restocking." <C id="returns-cost-and-badge-10"/> <C id="returns-cost-and-badge-11"/>

| Size tier and weight | Return fee per unit |
|---|---|
| Small standard, up to 4 oz | $3.22 |
| Small standard, over 12 oz to 16 oz | $3.55 |
| Large standard, over 1 lb to 2 lb | $4.70 |
| Large standard, over 3 lb to 20 lb | $5.60 + $0.40 per lb above 3 lb |
| Small bulky, up to 30 lb | $8.65 + $0.40 per lb above 2 lb |

*Source: Amazon Supply Chain, MCF rate card, checked Nov 8, 2026.* <C id="returns-cost-and-badge-12"/> <C id="returns-cost-and-badge-13"/> <C id="returns-cost-and-badge-14"/> <C id="returns-cost-and-badge-15"/> <C id="returns-cost-and-badge-16"/>

## What a return rate costs per unit sold

<Callout type="example" title="Worked example (hypothetical): spreading the return fee over sales">
Inputs: 100 units shipped through MCF; return fees from Amazon's published MCF table; return-related refunds and resale value left out. Large standard, 1–2 lb, 8 returns: 8 × $4.70 = $37.60, or $0.38 per unit sold. Same item, 15 returns: 15 × $4.70 = $70.50, or $0.71 per unit sold. Small standard, up to 4 oz, 8 returns: 8 × $3.22 = $25.76, or $0.26 per unit sold.
</Callout>

The example covers only the return fee, not the value of the returned unit.

<Callout type="example" title="Worked example (hypothetical): one SKU's returns in a month">
Inputs (invented): a large standard item of 1–2 lb sold through MCF; 400 units shipped in the month; 24 units returned, of which 18 are resellable and 6 damaged; product cost $9.00 per unit; 2 of the damaged units are later reimbursed at $9.00 each.

- MCF return fees: 24 × $4.70 = $112.80 (published rate for large standard, over 1 lb to 2 lb).
- Damaged units written off: 6 × $9.00 = $54.00, less 2 × $9.00 = $18.00 reimbursed, so $36.00.
- Total: $112.80 + $36.00 = $148.80, or about $0.37 per unit shipped.

Return fees are three-quarters of the cost here, so for this SKU cutting the return rate matters more than chasing reimbursements. Refunds to the customer are not counted because they reverse the sale rather than add a fee.
</Callout>

## Waivers for new products

The FBA New Selection program covers returns for new listings. Amazon says it will "waive return processing costs for up to 200 units of each parent ASIN." <C id="returns-cost-and-badge-06"/> Returned items "have to be received at a fulfillment center within 120 days of the first date the inventory was received." <C id="returns-cost-and-badge-07"/> Eligibility requires parent ASINs that have never been received at an Amazon fulfillment center, and an Inventory Performance Index (IPI) of 300 or higher. <C id="returns-cost-and-badge-09"/> <C id="returns-cost-and-badge-08"/>

## What happens to returned units

Amazon says "the vast majority of returns are resold as new or used, returned to selling partners, liquidated, or donated." <C id="returns-cost-and-badge-17"/> Items resold by Amazon are graded into one of four conditions: Like New, Very Good, Good or Acceptable. <C id="returns-cost-and-badge-18"/> For your own FBA stock, you can have Amazon return, dispose of or liquidate inventory in a fulfillment center for a per-item charge. <C id="returns-cost-and-badge-22"/>

## FBA returns and seller-fulfilled returns use different reports

Amazon's returns report types "only cover seller-fulfilled order returns"; FBA returns and returnless refunds are excluded, and for FBA returns Amazon points to the FBA Returns Report instead. <C id="returns-cost-and-badge-30"/> Pick the report by who fulfilled the order.

The FBA Returns Report lists each customer-returned unit received at a fulfillment center with return reason and disposition, and its fields include `return-date`, `order-id`, `sku`, `fnsku`, `quantity` and `fulfillment-center-id`, so you can join it to orders and to individual sites. <C id="returns-cost-and-badge-19"/> <C id="returns-cost-and-badge-27"/> It can only be requested and is updated daily. <C id="returns-cost-and-badge-26"/> To check that a return was actually counted back into stock, the Inventory Ledger summary view has a Customer Returns column next to receipts, shipments, lost, damaged and disposed units. <C id="returns-cost-and-badge-29"/>

## Where return money shows up in your settlement

Amazon's Finances API model defines several charge types that relate to returns. Refunds are a separate event list, and fee adjustments on an item "only returned for refunds, guarantee claims, and chargeback events". Read the refund and its fee adjustments together with the original sale before you total what a return cost. <C id="returns-cost-and-badge-36"/>

| Finances API name | What Amazon's model says it is |
|---|---|
| `RestockingFee` | "The charge that is applied to the buyer when returning a product in certain categories" |
| `ReturnShipping` | Money given to the buyer "to compensate for shipping the item back if we are at fault" |
| `FBAInventoryReimbursement` | An FBA inventory reimbursement to your account, which "occurs if a seller's inventory is damaged" |

*Source: Amazon Selling Partner API models, Finances API v0 (github.com/amzn), checked Nov 9, 2026.* <C id="returns-cost-and-badge-34"/> <C id="returns-cost-and-badge-35"/> <C id="returns-cost-and-badge-37"/>

The FBA Reimbursements Report itemizes reimbursements with the reason for each, and its `amount-per-unit`, `quantity-reimbursed-cash` and `quantity-reimbursed-inventory` columns show whether you were paid in cash or with replacement units. <C id="returns-cost-and-badge-23"/> <C id="returns-cost-and-badge-28"/>

## Where to check the returns charges on your account

Start with Amazon's FBA page at sell.amazon.com/fulfillment-by-amazon, which describes when the returns processing fee applies, and the MCF rate card at supplychain.amazon.com/docs/rate-card for MCF return fees. <C id="returns-cost-and-badge-01"/> <C id="returns-cost-and-badge-10"/> Match the fees on your settlement against the FBA Returns Report for the same period. <C id="returns-cost-and-badge-19"/> This page summarizes Amazon's published terms. A disputed returns charge or reimbursement is settled through a Seller Central support case.
