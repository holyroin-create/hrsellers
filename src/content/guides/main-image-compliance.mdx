If your main image breaks Amazon's rules, the risk is not a warning label but a listing customers cannot find: listing issues can cause search suppression, and a search-suppressed listing is no longer discoverable. <C id="main-image-compliance-11"/> <C id="main-image-compliance-13"/> Amazon requires all listing images to comply with its product image requirements. <C id="main-image-compliance-04"/> The detailed main image rules are published inside Seller Central, so read and apply them there; this page covers what Amazon documents publicly about the main image and how to catch problems early.

## What "main image" means in Amazon's catalog

Every listing stores its photos in named image slots. The main image is one specific attribute, separate from the gallery and the swatch.

| Slot | Attribute | What it is |
|---|---|---|
| MAIN | `main_product_image_locator` | Primary product image displayed on the detail page |
| PT01–PT08 | `other_product_image_locator_1` to `_8` | Additional images in the image gallery |
| SWCH | `swatch_product_image_locator` | Swatch image displayed on variation selectors |

*Source: Amazon Selling Partner API, "Submit media attributes," checked Nov 8, 2026.* <C id="main-image-compliance-01"/> <C id="main-image-compliance-02"/> <C id="main-image-compliance-03"/>

Amazon's seller site puts the overall count simply: you can upload up to nine photos. <C id="main-image-compliance-15"/> The product detail page is the part of a listing where the product's information appears, including the title and images, <C id="main-image-compliance-14"/> so the MAIN slot is the photo that represents the product there.

Two details matter for compliance. First, supported image slots and their requirements differ by product type and marketplace. <C id="main-image-compliance-05"/> Second, the product type definition returns every supported image attribute along with its constraints, <C id="main-image-compliance-06"/> so the authoritative list for your product is in the schema, not in a generic checklist.

## The photo requirements Amazon publishes on its seller site

Amazon's public photo guide on sell.amazon.com states a short list of hard requirements. Every product must have at least one image, Amazon recommends at least six, and all images must meet these terms: <C id="main-image-compliance-32"/>

| Requirement | What Amazon's guide says | Type |
|---|---|---|
| Size | 500 to 10,000 pixels on the longest side | Must |
| File format | JPEG, TIFF, PNG or non-animated GIF | Must |
| Quality | Clear, unpixellated, no jagged edges | Must |
| Zoom | Larger than 1,000 pixels on each side preferred, to allow zoom | Preference |
| Preferred format | JPEG | Preference |
| Background | In most cases, white (RGB 255, 255, 255) | Guidance |
| Frame fill | Product fills 85% or more of the frame | Guidance |
| Placement | Product placed centrally in every angle | Guidance |

*Source: Amazon, "6 tips for taking product photos in 2025" on sell.amazon.com (Dec 4, 2024), checked Nov 9, 2026.* <C id="main-image-compliance-27"/> <C id="main-image-compliance-28"/> <C id="main-image-compliance-29"/> <C id="main-image-compliance-30"/> <C id="main-image-compliance-31"/> <C id="main-image-compliance-33"/> <C id="main-image-compliance-34"/> <C id="main-image-compliance-35"/>

The same site's listing guide adds that images should be sharp and clear, ideally in high resolution, <C id="main-image-compliance-16"/> and that the product should be shown against a simple backdrop and well lit. <C id="main-image-compliance-17"/>

These are general photo rules, not the full main image policy. Amazon's developer guide lists compliance with its product image requirements, which are published in Seller Central, as a prerequisite for every image. <C id="main-image-compliance-04"/> Look up the "product image requirements" page there for your category before you shoot, because requirements vary by product type. <C id="main-image-compliance-05"/>

<Callout type="example" title="Worked example (hypothetical): three files checked against the published numbers">
Inputs: file A is 800 × 800 pixels PNG; file B is 2,400 × 1,600 pixels JPEG; file C is 12,000 × 8,000 pixels TIFF.

File A: longest side 800, inside the 500–10,000 range, so it meets the size requirement, but it is below the 1,000-pixel-per-side preference for zoom. File B: longest side 2,400 and shortest side 1,600, so it meets the requirement and the zoom preference, in the preferred format. File C: longest side 12,000, above the 10,000-pixel maximum, so it fails the size requirement and needs resizing before upload. On these numbers alone, B is the only file that meets every published size and format point; the Seller Central rules for the category still have to be checked.
</Callout>

How you host and replace an image affects whether a corrected photo actually goes live.

Amazon recommends hosting media on AWS for optimal processing performance. <C id="main-image-compliance-26"/>

The immutability rule matters when you fix a non-compliant photo: if you overwrite a file in a private S3 bucket under the same key, Amazon treats that content as unchanged. Upload the corrected image under a new key. <C id="main-image-compliance-08"/> If you are updating many SKUs at once, the JSON_LISTINGS_FEED accepts images for multiple SKUs in one feed document. <C id="main-image-compliance-10"/> Some image variants exist only in Seller Central's Image Manager and are not available through the Listings Items API. <C id="main-image-compliance-09"/>

## How Amazon reports an image problem on your listing

Amazon reports problems with a listing as "issues." Issues point out problems that cause listings to go inactive, search suppression, or other quality problems. <C id="main-image-compliance-11"/> Amazon's documented enforcement actions include search suppression, listing suppression, attribute suppression and catalog item removal. <C id="main-image-compliance-12"/>

Each issue in the Listings Items API carries fields that tell you whether a photo is the cause and how urgent it is:

| Field | Values relevant to images | What the value means |
|---|---|---|
| `categories` | INVALID_IMAGE | One or more images are invalid |
| `categories` | MISSING_IMAGE | One or more required images are missing |
| `severity` | ERROR / WARNING | ERROR prevents the submission from processing; WARNING should be reviewed but did not block it |
| `enforcements.exemption.status` | EXEMPT / EXEMPT_UNTIL_EXPIRY_DATE / NOT_EXEMPT | EXEMPT: permanent exemption; EXEMPT_UNTIL_EXPIRY_DATE: exempt until a set date; NOT_EXEMPT: enforcement already applied |

*Source: Amazon Selling Partner API models, Listings Items API 2021-08-01, checked Nov 9, 2026.* <C id="main-image-compliance-36"/> <C id="main-image-compliance-37"/> <C id="main-image-compliance-38"/> <C id="main-image-compliance-47"/> <C id="main-image-compliance-39"/>

The exemption status is the deadline to watch. EXEMPT_UNTIL_EXPIRY_DATE is a temporary exemption, and after the date in the expiryDate field, Amazon enforces the listed actions. <C id="main-image-compliance-40"/> For an issue in that state, the listed enforcement actions are not applied until that date passes.

The issue message is the specific reason; Amazon's status guide notes that buyability and discoverability can be affected by suppression, blocking, missing offers, depleted inventory and other reasons. <C id="main-image-compliance-20"/> Do not assume an image is the cause until the issue says so.

## Checking which main image is live

After you upload, check what Amazon is actually showing rather than what you sent. The listing summary returned by the Listings Items API includes mainImage, "the listings item's main image," with its link, height and width in pixels. <C id="main-image-compliance-42"/> The Catalog Items API returns catalog images with a variant such as MAIN or PT01, plus height and width in pixels, <C id="main-image-compliance-43"/> so you can confirm both the slot and that the live file meets the pixel range above.

You can also be alerted when images change: the BRANDED_ITEM_CONTENT_CHANGE notification lists changed attributes, but Amazon notes that the image attributes all mean the same thing for now: if any image changes, all the image attributes appear in the notification. <C id="main-image-compliance-44"/> Treat it as "an image changed," then open the catalog images to see which one.

## Main image versus ad creative

Ad images follow a different rulebook from the main image, so do not reuse ad rules as listing rules or the reverse. Amazon Ads says display ads' default creative uses product imagery from the advertised ASIN's detail page and supports a white background, <C id="main-image-compliance-21"/> but custom ad creative has its own moderation policy.

| Amazon Ads moderation rule | Applies to |
|---|---|
| Low-quality images will be rejected | Sponsored Brands and display ad creative |
| Images should be the highest image resolution possible of 72 ppi | Sponsored Brands and display ad creative |
| Ads without borders cannot have a white or off-white background color | Ad creative without borders (each ad product's specs give details) |

*Source: Amazon Ads, Sponsored Brands and Sponsored Display moderation guide, checked Nov 8, 2026.* <C id="main-image-compliance-22"/> <C id="main-image-compliance-23"/> <C id="main-image-compliance-24"/>

Amazon Ads' component-based creative (the Asset-based and Brand Store creative formats) goes further in the other direction. Its custom images must not be "on a white or transparent background," <C id="main-image-compliance-45"/> and must be at least 600 by 600 pixels and 5MB or smaller. <C id="main-image-compliance-46"/>

## Where to re-check the image rules

The binding main image rules are on the product image requirements page in Seller Central; read it for your category before each reshoot. For how the MAIN slot, hosting and image constraints work through the API, re-check Amazon's photo guide (sell.amazon.com/blog/product-photos) for the published size and format requirements, the "Submit media attributes" guide (developer-docs.amazon.com/sp-api/docs/submit-media) and the listing status guide on the same site. If a listing is suppressed, the issue code and message Amazon returns for that listing decide what must change.
