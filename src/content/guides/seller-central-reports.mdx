Amazon offers many seller reports, and the practical task is matching a question — what was I paid, where did my inventory go, what did FBA charge, why is my account health slipping — to the report that answers it. Amazon defines a report simply as "a type of tool that provides sellers with specific information about their business or performance." <C id="seller-central-reports-28"/> This page maps common questions to the report that answers them, using the report descriptions in Amazon's Selling Partner API documentation. Where the menu path inside Seller Central matters, check it there.

Two rules apply across the board. Settlement reports "cannot be requested or scheduled" because "they are automatically scheduled by Amazon." <C id="seller-central-reports-06"/> <C id="seller-central-reports-07"/> And where Amazon specifies no retention period for a report type, "the report will be retained for 90 days." <C id="seller-central-reports-02"/> If your accountant will need a file next year, download it now.

## Money: what you were paid and why

For payouts, start with the settlement reports. The current flat-file version is the Flat File V2 Settlement Report, which "replaces the Flat File Settlement Report and XML Settlement Report." <C id="seller-central-reports-08"/> For a quick view, Seller Central's Payments Dashboard shows "sales, expenses, and refunds," and the Amazon Seller app lets you "view payments, and find current and past statements." <C id="seller-central-reports-27"/> <C id="seller-central-reports-26"/>

If money is being held back, the Deferred Transaction Report is "a point-in-time report that contains a list of deferred transactions," and "a single report can provide up to 10 years of data." <C id="seller-central-reports-23"/> For bookkeeping that matches revenue to cost of goods, see the [accrual accounting and COGS guide](/guides/accrual-accounting-cogs/); for tax reporting of marketplace payments, see the [Form 1099-K guide](/guides/form-1099-k-marketplace-sellers/).

## FBA inventory and fees

For FBA unit movements, use the Inventory Ledger. Amazon's description of its summary view: "The Inventory Ledger Report is like a bank statement of your inventory." <C id="seller-central-reports-13"/> The detailed view lets you "view all historical movements of your inventory for 18 months." <C id="seller-central-reports-14"/> For a snapshot of what is in stock now, the Manage Inventory report "contains current details of active (not archived) inventory including condition, quantity, and volume." <C id="seller-central-reports-29"/>

| FBA report | What Amazon says it contains |
|---|---|
| Reimbursements | Itemized inventory reimbursements, including the reason for each |
| Returns | Customer returns received at a fulfillment center, with return reason and disposition |
| Storage Fees | Estimated monthly storage fees for each ASIN |
| Long Term Storage Fee Charges | The charge data for long-term storage |
| Fee Preview | Estimated selling and fulfillment fees for FBA inventory with active offers |
| Removal Order Detail | All removal orders, with their items, in a chosen period |

*Source: Amazon Selling Partner API documentation, FBA report types, checked Nov 8, 2026.* <C id="seller-central-reports-15"/> <C id="seller-central-reports-16"/> <C id="seller-central-reports-17"/> <C id="seller-central-reports-19"/> <C id="seller-central-reports-18"/> <C id="seller-central-reports-20"/>

FBA data is not live to the minute: Amazon says a near real-time FBA report is generated "no more than once every 30 minutes" and a daily one "no more than once every four hours." <C id="seller-central-reports-21"/> <C id="seller-central-reports-22"/> If a number looks stale, that refresh interval is the first thing to rule out.

<Callout type="example" title="Worked example (hypothetical): checking a ledger month">
Inputs for one SKU over a month: starting balance 500 units; receipts 300; customer shipments 420; customer returns put back into stock 10; units found damaged 4. Expected ending balance: 500 + 300 − 420 + 10 − 4 = 386. If the ledger's ending balance shows 380, six units are unexplained. The next steps are to look for those units in the Reimbursements report (was the loss already paid for?) and the Removal Order Detail report (were they removed on your instruction?), and only then to open a case.
</Callout>

The example treats the ledger the way Amazon's bank-statement comparison suggests, and the Reimbursements report lists the reason for each reimbursement. <C id="seller-central-reports-13"/> <C id="seller-central-reports-15"/>

## Account health and feedback

The Seller Performance Report "contains the individual performance metrics data from the Seller Central Account Health dashboard," and the Flat File Feedback Report "contains negative and neutral feedback (one to three stars)." <C id="seller-central-reports-24"/> <C id="seller-central-reports-25"/> The [order defect rate guide](/guides/order-defect-rate/) explains how to read the order metrics, and the [account suspension appeal guide](/guides/account-suspension-appeal/) covers the policy side.

Sellers who pull reports through software use the Reports API, which Amazon describes as the way "to retrieve and manage reports that you can use to manage your selling business." <C id="seller-central-reports-01"/>

## How to confirm a report's contents

Report names, fields and limits change; Amazon notes some older formats have already been replaced. <C id="seller-central-reports-08"/> Check the report type pages in the Selling Partner API documentation at developer-docs.amazon.com (Payment, Order, Settlement, FBA, Analytics and Performance reports) for the current description and date limits, and Seller Central Help for where each report sits in the Seller Central menus.
