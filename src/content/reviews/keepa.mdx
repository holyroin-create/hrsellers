This page summarizes what Keepa publishes about its own product on keepa.com and in its API documentation, checked on November 8 and again on November 9, 2026. We have not tested the software, we do not rate it, and this site has no affiliate relationship with Keepa. Keepa's own pages describe a price-history service and an API, so the decisions are narrow: whether its data covers the Amazon marketplaces you sell or source in, and, if you plan to pull its data into your own spreadsheets or software, how its token-based API plans are billed.

## What Keepa says it is

Keepa says it provides Amazon price history charts and price drop alerts. <C id="keepa-02"/> Its site also lists price watches, daily drops and browser extensions among its features, <C id="keepa-03"/> and says it tracks over 7 billion Amazon products. <C id="keepa-24"/>

## Prices: only on Keepa's API plans page

Keepa's API documentation links to an "API plans" page on keepa.com for current plans and prices. That page loads as an interactive application and showed no plan prices as text when it was checked on November 8 and November 9, 2026, so no prices are stated here. Two pricing rules are published in the documentation: Keepa does not offer discounts, <C id="keepa-25"/> and plans differ by the number of tokens generated per minute. <C id="keepa-09"/>

## How the API plans are structured

API access is limited by a token bucket, and plans differ by the number of tokens generated per minute. <C id="keepa-09"/> Unused tokens expire after 60 minutes, so a plan generating 60 tokens a minute has a bucket capacity of 3,600 tokens. <C id="keepa-10"/> Each request spends tokens:

| Request (as named in Keepa's docs) | Published token cost |
|---|---|
| Product Request | 1 token per product, up to 100 products per request |
| Offers (optional, per product) | 6 tokens per found offer page (up to 10 offers), replacing the 1-token base cost |
| Product Search | 10 tokens per search, up to 20 results |
| Browsing Deals | 5 tokens per request, up to 150 deals |
| Best Sellers | 50 tokens per request |
| Product Finder | 10 tokens plus 1 per 100 ASINs |
| Seller Information | 1 token per seller, plus 9 for the storefront |

*Source: Keepa API documentation, checked Nov 9, 2026.* <C id="keepa-06"/> <C id="keepa-07"/> <C id="keepa-17"/> <C id="keepa-18"/> <C id="keepa-29"/>

On a Product Request, several options are free and some are not:

| Product Request option | Extra token cost |
|---|---|
| stats, history, days, only-live-offers | None <C id="keepa-30"/> |
| buybox (all Buy Box data) | 2 per product <C id="keepa-31"/> |
| rating | Up to 1 per product <C id="keepa-31"/> |
| update (force a refresh if data is older than the hours you set) | 0 or 1 per product <C id="keepa-31"/> <C id="keepa-32"/> |
| offers | 6 per found offer page <C id="keepa-07"/> |

*Source: Keepa API documentation, Product Request page, checked Nov 9, 2026.* <C id="keepa-30"/>

<Callout type="example" title="Worked example (hypothetical): sizing a refresh of your catalog">
Inputs: a list of 300 ASINs refreshed with basic Product Requests at 1 token per product, <C id="keepa-06"/> on a plan that generates 60 tokens a minute with a 3,600-token bucket. <C id="keepa-10"/> A full refresh uses 300 × 1 = 300 tokens, which fits inside a full bucket. Requesting offers instead costs 6 tokens per found offer page and replaces the 1-token base cost, <C id="keepa-07"/> so one offer page per product raises the refresh to 300 × 6 = 1,800 tokens, half of the bucket. A weekly screen of 1,000 ASINs with the free stats option plus buybox costs 1,000 × (1 + 2) = 3,000 tokens, <C id="keepa-31"/> close to the whole 3,600-token bucket in one pass. Run the same arithmetic with your own ASIN count before picking a plan size.
</Callout>

If you overspend, requests fail with HTTP 429 until the bucket refills, <C id="keepa-33"/> and every response tells you tokensLeft and tokensConsumed, <C id="keepa-34"/> so a script can read its remaining balance from each response.

Tracking adds a standing cost. Keepa's Tracking API tracks product changes and notifies you by webhook push or API pull, <C id="keepa-19"/> and each tracked product lowers your token refill rate, at 0.9 tokens per update per locale for regular tracking. <C id="keepa-20"/>

## What data the API returns

The Keepa API delivers Keepa's data on Amazon marketplaces to your own application. <C id="keepa-04"/> Every request requires your API access key, <C id="keepa-15"/> requests are issued over HTTPS, and responses are always JSON. <C id="keepa-16"/> Product data can include New and Used Buy Box information with a history of Buy Box winners, <C id="keepa-07"/> and statistics with quick access to current prices, min/max prices and weighted mean values. <C id="keepa-08"/>

## Which Keepa field answers which sourcing question

Product histories arrive in a csv array indexed by price type, and summary figures in a statistics object. The documented fields that map to common sourcing questions:

| Your question | Where Keepa puts it | What the docs say it holds |
|---|---|---|
| Has Amazon itself been selling, and at what price? | csv index 0, AMAZON | Amazon price history <C id="keepa-36"/> |
| What has the lowest New offer been? | csv index 1, NEW | Marketplace New price history <C id="keepa-36"/> |
| What has the lowest FBA competitor charged? | csv index 10, NEW_FBA | Lowest third-party New offer fulfilled by Amazon <C id="keepa-38"/> |
| What has the Buy Box cost a buyer? | csv index 18, BUY_BOX_SHIPPING | New Buy Box price including shipping <C id="keepa-40"/> |
| How crowded is the listing? | csv index 11, COUNT_NEW | Count of merchants selling it new <C id="keepa-39"/> |
| How fast does it sell? | csv index 3, SALES; monthlySold | Sales rank history; <C id="keepa-37"/> purchases in the past month <C id="keepa-42"/> |
| How has the star rating moved? | csv index 16, RATING | Integer 0–50, where 45 = 4.5 stars <C id="keepa-41"/> |
| Is Amazon or FBA holding the Buy Box? | stats: buyBoxIsAmazon, buyBoxIsFBA | Flags for Amazon as seller and FBA fulfillment <C id="keepa-46"/> |
| How often is it out of stock, and how often does rank drop? | stats: outOfStockPercentage30, salesRankDrops30 | 30-day out-of-stock share; count of rank drops <C id="keepa-45"/> |
| What will Amazon charge me? | fbaFees, referralFeePercentage | FBA pick & pack fee; referral fee % at the assumed price <C id="keepa-43"/> |

*Source: Keepa API documentation, Product Object and Statistics Object pages, checked Nov 9, 2026.* <C id="keepa-36"/>

Not every product has a sales rank, and variation items usually lack individual ranks, <C id="keepa-37"/> so an empty SALES series is not by itself a sales figure. The stats window can be a number of recent days or an explicit date range. <C id="keepa-47"/> Amazon's own fees are set on Amazon's pages, covered in our [referral fee guide](/guides/amazon-referral-fees/).

## Reading the raw numbers correctly

<Callout type="example" title="Worked example (hypothetical): decoding one data point">
Inputs: an amazon.com NEW series point with time 7,000,000 and value 2499, then a later point with value -1.

Prices are integers in the locale's smallest currency unit, <C id="keepa-35"/> so 2499 is $24.99. A -1 means no offer was available in that interval, such as out of stock, <C id="keepa-49"/> not a price of minus one cent. Times are Keepa Time minutes: (7,000,000 + 21,564,000) × 60,000 = 1,713,840,000,000 Unix milliseconds, <C id="keepa-44"/> which is April 23, 2024 (UTC).
</Callout>

One definition changed in 2026. For the NEW, USED, COLLECTIBLE and REFURBISHED series, entries before February 23, 2026 are the lowest listing price, and entries from that date on are the lowest landing price, listing plus shipping. <C id="keepa-48"/> A series that spans that date therefore mixes two definitions; BUY_BOX_SHIPPING is defined as the New Buy Box price including shipping costs. <C id="keepa-40"/>

## Amazon's own tools on pricing and demand

Amazon offers related views inside Seller Central. Product Opportunity Explorer groups products into niches built from customer search terms and analyzes trends in pricing, reviews and returns. <C id="keepa-21"/> Amazon's Automate Pricing tool is described as increasing your chances of becoming the Featured Offer. <C id="keepa-23"/> Both come with a Professional selling account, which Amazon lists at $39.99 a month plus selling fees. <C id="keepa-22"/> For what Amazon charges on each sale, see our [referral fee guide](/guides/amazon-referral-fees/).
